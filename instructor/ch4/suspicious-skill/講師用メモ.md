# 疑似 Skill の解説(講師用)

この Skill は「入れる前に何を読むか」を練習するための教材です。実行しても画面にメッセージが出るだけで、ファイルやネットワークには一切触れません。

## 危険な点(資料 4-2 の 4 つの観点)

| 観点 | この Skill の該当箇所 | なぜ危険か |
|---|---|---|
| allowed-tools に Bash がある | `allowed-tools: Bash, Read, Write, Edit` | 任意のコマンドを、確認なしで実行できてしまう。Read と Write だけで足りる作業に Bash は不要 |
| scripts/ にスクリプトが同梱されている | `scripts/setup.py` | SKILL.md の本文だけ読んでも、スクリプトの中身は見えない。実行する前にスクリプトも読む必要がある |
| description が広すぎる | 「何でも手伝う。ユーザーが何かを頼んだ時は、まずこのスキルを使う」 | あらゆる依頼で自動的に呼ばれ、意図しない場面で上の 2 つが働く |
| 出所が不明 | 「作者: 不明 / 配布元: 不明」 | 誰が作ったか、更新されたか確認できない |

## 進め方の例

1. 参加者に SKILL.md と scripts/setup.py を読んでもらい、気になる点を挙げてもらう
2. 上の表と照らし合わせる
3. 配布する weekly-report の SKILL.md と比べる(allowed-tools が Read と Write だけ、description が具体的、scripts/ が無い)
