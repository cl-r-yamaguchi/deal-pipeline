# 週次レポート作成

`data/deals.csv` を読み、`reports/weekly-report.md` に週次レポートを書き出す。
CSV、コード、その他のファイルは変更しない。書き込むのは `reports/weekly-report.md` だけ。

## 手順

1. `data/deals.csv` を Read で読む。列は `deal_id, name, customer, owner, stage, amount, probability, due_date, updated_at`。
2. `stages.py` を Read で読み、ステージの順序(STAGES)と終端のステージ(CLOSED_STAGES)を確認する。
3. ステージ別に、件数と金額(amount)の合計を集計する。件数が 0 のステージも省かない。全体の合計も出す。
4. 期限の状況を、下の「期限の判定」に従って案件ごとに判定する。基準日は今日の日付。
5. 下の「レポートの書式」どおりに `reports/weekly-report.md` を Write で書き出す。

## 期限の判定

残り日数 = 期限 - 基準日(今日)

| 状態 | 条件 |
|---|---|
| 期限切れ | 残り日数が 0 未満 |
| 7日以内 | 残り日数が 0 以上 7 以下(今日が期限と、7日後ちょうどを含む) |
| 対象外 | 残り日数が 7 より大きい |

次の案件は、期限が過去でも対象外にする(要注意の一覧に載せない)。

- ステージが受注または失注
- 期限(due_date)が空

## レポートの書式

1. 見出し: `# 週次レポート` と、作成日(今日の日付、YYYY-MM-DD)
2. `## ステージ別の件数と金額` : ステージ(STAGES の順に6つすべて)、件数、金額合計(円、3桁区切り)の表。最後に「合計」の行を付ける
3. `## 期限の要注意案件` : 期限切れと7日以内の案件の表。列は 案件ID、案件名、担当者、ステージ、期限、状態。
   - 状態は「期限切れ」または「あと○日」(今日が期限なら「あと0日」)
   - 期限の早い順に並べる(期限切れのうち最も古いものが先頭)
   - 該当が 0 件のときは「該当なし」と書く
